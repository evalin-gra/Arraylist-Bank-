# 🏦 ArrayList Bank

### A Simple Banking Simulation with Java ☕

## ✨ About the Project

**ArrayList Bank** adalah program simulasi rekening bank sederhana yang dibuat untuk memenuhi tugas mata kuliah **Pemrograman Berorientasi Objek (PBO)**. Proyek ini menggunakan Java untuk menerapkan konsep OOP dan `ArrayList` dalam pengelolaan data nasabah dan rekening bank.

## 🚀 Features

- 👤 Customer Management
- 💳 Account Management
- 💰 Deposit
- 💸 Withdraw
- 📋 Account Information

## 🧠 Concepts Applied

- **Class & Object** — Membuat representasi nasabah dan rekening.
- **Encapsulation** — Mengatur akses terhadap atribut.
- **Constructor** — Menginisialisasi objek.
- **Methods** — Mengelola proses transaksi.
- **ArrayList** — Menyimpan dan mengelola kumpulan objek.

## 🛠️ Tech Stack

- ☕ Java
- 📦 ArrayList
- 🧩 Object-Oriented Programming (OOP)

## 🎯 Learning Goals

- Memahami konsep dasar OOP dalam Java.
- Menerapkan class, object, constructor, dan method.
- Memahami penggunaan enkapsulasi.
- Menggunakan `ArrayList` untuk menyimpan objek.
- Melatih logika program melalui simulasi transaksi bank.

## 📝 Project Note

Proyek ini dibuat sebagai bagian dari pembelajaran Pemrograman Berorientasi Objek. Program ini merupakan simulasi sederhana untuk memahami penerapan konsep OOP dalam kasus sehari-hari.
